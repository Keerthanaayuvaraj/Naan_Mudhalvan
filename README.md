# 🛒 Customer Orders Management System

A simple web-based application to manage customer orders, built using **Java (Spring Boot)** for the backend. This system supports basic authentication, role management, and order tracking features.

---

## 🚀 Features

- 👤 Customer registration and login  
- 🔒 Secure authentication using **JWT**  
- 📝 Create and view customer orders  
- 👮‍♂️ Role-based access (Customer / Admin)  
- 🌐 RESTful APIs for integration and testing (Postman-friendly)
